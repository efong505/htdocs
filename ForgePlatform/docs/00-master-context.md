# Forge Ecosystem Master Context

## Overview
Forge is a business systems and infrastructure ecosystem focused on operational ownership, lightweight tooling, automation, and modern serverless infrastructure.

## Products
- BackForge
- LicenseForge
- DripForge
- ShieldForge

## Platform Goal
Build a unified Forge platform using AWS serverless architecture and Terraform infrastructure management.

## Architecture Direction
- S3 static hosting
- CloudFront
- API Gateway
- Lambda
- DynamoDB
- SES/SNS
- GitHub Actions CI/CD
- modular Terraform architecture

## Purpose of Platform
The Forge platform should:
- explain the ecosystem
- host product pages
- support lead generation
- support plugin licensing
- support downloads
- support customer portals
- support future SaaS-like infrastructure
- act as a practice/production implementation similar to ChristianConservativesToday.com

## Philosophy
Forge emphasizes:
- ownership
- lightweight tooling
- no bloat
- infrastructure control
- self-hosted systems
- operational resilience
